Factoriza como un experto: trinomio cuadrado perfecto por suma y resta

Una ruta corta y clara: entiendes la teoría desde cero, aprendes el método, lo ves resuelto y lo pones a prueba hasta que te salga solo.

a4 + a2b2 + b4 = (a2 + ab + b2)(a2 − ab + b2)

1Teoría fácil: ¿qué es un TCP?

Empecemos sin miedo. Elevar al cuadrado es multiplicar algo por sí mismo. Por ejemplo, 5² = 5·5 = 25 y también (a + b)² = (a + b)·(a + b).

Si multiplicas (a + b)·(a + b), siempre te sale un resultado con tres términos. A ese resultado se le llama trinomio cuadrado perfecto (TCP):

(a + b)² = a² + 2ab + b²

Piensa en un cuadrado grande de lado (a + b). Se parte en 4 zonas: un cuadrado a², otro cuadrado b² y dos rectángulos ab. Los dos rectángulos juntos forman el 2ab del medio.

Receta para armar un TCP:
1) cuadrado del primero, 2) el doble de primero por segundo, 3) cuadrado del segundo.
Palabras que vas a usar
  • Raíz cuadrada: el número que multiplicado por sí mismo da el otro. √9 = 3, √x⁴ = x² (se divide el exponente entre 2).
  • Doble producto: multiplicar las dos raíces y luego por 2. Es el término del medio que “debería” estar.
  • Diferencia de cuadrados: una resta de dos cuadrados se factoriza así: A² − B² = (A + B)(A − B). Ejemplo: x² − 4 = (x + 2)(x − 2).

2La idea clave: sumar y restar lo mismo

Mira este trinomio: a⁴ + a²b² + b⁴. Sus raíces son a² y b², y parece un TCP, pero el doble producto sería 2·a²·b² = 2a²b² y solo tenemos a²b². Falta una a²b².

Solución: la agregamos. Pero si agregas algo, cambias la expresión. Entonces la quitamos enseguida. Es como 10 + 5 − 5: sigues teniendo 10.

a⁴ + a²b² + a²b² + b⁴ − a²b²

Ahora agrupamos: lo primero es un TCP y lo que queda es un cuadrado restado.

(a⁴ + 2a²b² + b⁴) − a²b² = (a² + b²)² − (ab)²

Eso es una diferencia de cuadrados, con A = a² + b² y B = ab. Se factoriza como (A + B)(A − B):

Fórmula que debes memorizar
a⁴ + a²b² + b⁴ = (a² + ab + b²)(a² − ab + b²)

Fíjate: los dos factores son casi iguales. Solo cambia el signo del término ab.

3El método en 5 pasos

  1. Ordena el trinomio de mayor a menor exponente.
  2. Saca la raíz del primer y del último término. Serán tus “a” y “b”.
  3. Calcula el doble producto (2·a·b). Es el medio que debería haber.
  4. Compara: lo que falte lo sumas y lo restas a la vez.
  5. Factoriza: el TCP queda como (algo)² y el término restado como otro cuadrado. Usa (A + B)(A − B) y ordena.
Atajo: si el trinomio tiene exactamente la forma a⁴ + a²b² + b⁴, aplica la fórmula directamente y te ahorras los pasos.
¿Cómo lo reconozco? Tiene tres términos, el primero y el último tienen raíz cuadrada exacta, y el del medio no coincide con el doble producto.

4Ejemplos resueltos paso a paso

Ejemplo 1 (fórmula directa): x⁴ + x²y² + y⁴

Compara con la fórmula a⁴ + a²b² + b⁴: aquí a = x y b = y.
Reemplaza en (a² + ab + b²)(a² − ab + b²):
Respuesta: (x² + xy + y²)(x² − xy + y²)

Ejemplo 2 (fórmula con “a” compuesta): 16x⁴ + 4x²y² + y⁴

Raíces: √16x⁴ = 4x² y √y⁴ = y². Entonces a² = 4x² → a = 2x, y b = y.
Verifica el medio: a²b² = (2x)²·y² = 4x²y² ✔ (es el que tenemos).
Reemplaza: a² = 4x², ab = 2xy, b² = y².
Respuesta: (4x² + 2xy + y²)(4x² − 2xy + y²)

Ejemplo 3 (suma y resta completa): x⁴ + 3x² + 4

Raíces: x² y 2. Doble producto: 2·x²·2 = 4x².
Comparar: tenemos 3x², nos falta x².
Sumar y restar: x⁴ + 3x² + x² + 4 − x²
Agrupar: (x⁴ + 4x² + 4) − x² = (x² + 2)² − x²
Respuesta: (x² + 2 + x)(x² + 2 − x) = (x² + x + 2)(x² − x + 2)

Ejemplo 4 (sin término del medio): m⁴ + 64

Raíces: m² y 8. Doble producto: 2·m²·8 = 16m². No hay medio, así que sumamos y restamos 16m².
m⁴ + 16m² + 64 − 16m² = (m² + 8)² − (4m)²
Respuesta: (m² + 4m + 8)(m² − 4m + 8)

Ejemplo 5 (con signo negativo): x⁴ − 3x² + 1

Para un TCP restado necesitamos −2x², pero tenemos −3x². Nos “sobra” x², así que sumamos x² y restamos x².
x⁴ − 3x² + x² + 1 − x² = (x² − 1)² − x²
Respuesta: (x² + x − 1)(x² − x − 1)
Comprueba tú mismo: multiplica los factores del Ejemplo 1. Los términos del medio (x³y y −x³y, etc.) se cancelan y vuelve x⁴ + x²y² + y⁴.

5Errores que debes evitar

Solo sumar, sin restar. Si sumas x² y no lo restas, cambiaste la expresión. Siempre van los dos.
Olvidar el cuadrado del término que restas. Si restas 9a²b², recuerda que es (3ab)², no 3ab.
Descuidar los signos al final. Al abrir (x² + 1 + x)(x² + 1 − x), ordena cada factor: x² + x + 1 y x² − x + 1.
Comprobación segura: multiplica tus dos factores. Si obtienes el trinomio original, está correcto.

6Mini examen

Sumar y restar lo mismo no cambia nada; ahí está toda la magia.
